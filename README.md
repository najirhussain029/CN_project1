TCP-chatroom
A simple client–server chat app using Python sockets.

📌 Features

Public chat
Private message using @username
Show online users (/users)
Exit chat using /exit or /quit
📂 Files server.py → runs the server client.py → runs the client

▶️ How to Run Start server: python server.py

Start client (open new terminal): python client.py

🛠️ Tech Used

Python
socket
threading
